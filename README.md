# Bot Programador (Gemini + Flask)

Asistente de programación con backend en Flask y motor LLM usando Google Gemini Flash.

## 🚀 Stack
- Python 3.11+
- Flask
- Google Gemini (Flash)
- Frontend HTML simple

## 📂 Estructura
- `backend/`: API y motor del bot
- `frontend/`: Interfaz web
- `.env`: variables de entorno (NO se sube)
